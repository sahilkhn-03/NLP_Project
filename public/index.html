ℹ️ How does the NLP pipeline work?
1
Text Normalisation

Lowercases, expands contractions (who's → who is), strips irrelevant punctuation.

2
Table Detection

Keywords like student, course, enrollment resolve to their schema tables.

3
Intent & Aggregation

Recognizes count, average, top N, highest to determine SELECT / COUNT / AGGREGATE.

4
Filter Extraction

Conditions like more than 80 marks become parameterized WHERE clauses with ?.

5
Sort & Limit

Top 5, descending, lowest set ORDER BY and LIMIT clauses deterministically.

6
Join Resolution

Cross-table relations trigger a validated 3-table JOIN across students and courses.

7
Security Validation

Only SELECT queries pass. Multi-statement attacks and forbidden tokens are rejected.

8
Live Execution

Executes against SQLite database and renders reactive results with microsecond latency.
